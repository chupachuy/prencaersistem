1. RESUMEN GENERAL
==============================================================================

Se implementó un sistema completo de evaluaciones prenatales estructuradas
en 3 trimestres, reemplazando el antiguo módulo monolítico "Reportes 1er
Trimestre" por una arquitectura relacional normalizada. El sistema utiliza
datos estructurados (BOOLEAN, ENUM, DECIMAL) en lugar de texto libre,
alineándose a estándares médicos internacionales (FMF, ESHRE-ESGE, FIGO,
RCIU Barcelona, Doppler).


2. ARQUITECTURA
==============================================================================

2.1 Tabla compartida (1)

   historial_clinico
   - Vinculada a pacientes (1:1)
   - Factores de riesgo: hipertensión, diabetes, lupus, SAF, preeclampsia,
     fertilización in vitro, parto pretérmino
   - Compartida por los 3 trimestres — se autocompleta al cambiar de
     trimestre para el mismo paciente

2.2 1er Trimestre (6 tablas, código EV1T-XXXX-YYYY)

   evaluaciones_1er_trimestre      Central: signos vitales, FUM, FPP, LCC
   anatomia_fetal                  SNC simetría plexos, situs, eje cardíaco
   marcadores_fmf                  TN, hueso nasal, ductus venoso, UTA PI
   entorno_materno                 Placenta, cérvix, ESHRE-ESGE, miomas
   impresion_diagnostica           Cromosomopatías, preeclampsia temprana

2.3 2do Trimestre (6 tablas, código EV2T-XXXX-YYYY)

   evaluaciones_2do_trimestre      Central: PAM, UTA PI, FPP actual, EG
   biometria_2do_trimestre         Peso fetal, percentil Hadlock, CI, FL/AC
   anatomia_fetal_2do_trimestre    8 órganos: cráneo, cara, corazón, tórax,
                                   abdomen, genitourinario, columna, extrem.
   marcadores_ecograficos_2do_trimestre  8 marcadores cromosomopatías
   entorno_placentario_2do_trimestre  OCI, acretismo FIGO, funneling, sludge
   impresion_diagnostica_2do_trimestre  Cromosomopatías, preeclampsia,
                                         parto pretérmino (4 niveles)

2.4 3er Trimestre (6 tablas, código EV3T-XXXX-YYYY)

   evaluaciones_3er_trimestre      Central: situación/presentación/posición
                                   fetal, TA, EG, FCF
   antecedentes_3er_trimestre      CTG, diabetes gestacional, mov. fetales,
                                   amenaza parto pretérmino, plan nacimiento
   crecimiento_3er_trimestre       Peso fetal, percentil, RCIU Barcelona
                                   (Estadio I-IV)
   doppler_3er_trimestre           AU PI, flujo diastólico, ACM PI, DV onda
                                   A, UTA PI, ratio CU/ICP, alteración detect.
   anatomia_liquido_3er_trimestre  Circular cordón, líquido amniótico
                                   (Phelan/Bolsillo Máximo), oligo/polihidr.
   evaluacion_placentaria_3er_trimestre  OCI, grosor, madurez (0-3), lagunas
                                         vasculares, interfase, vasos puente,
                                         acretismo FIGO PAS (Grado 0-3)

2.5 Total: 19 tablas

5. CARACTERÍSTICAS TÉCNICAS
==============================================================================

5.1 Base de datos
   - Charset: utf8mb4 con collation utf8mb4_unicode_ci
   - Engine: InnoDB con foreign keys y ON DELETE CASCADE
   - UNIQUE KEY en cada tabla vinculada (1 evaluación = 1 registro hijo)
   - Índices en paciente_id y codigo_reporte
   - Soft-delete (activo = 0) — no se borran datos físicamente

5.2 Seguridad
   - Auth::check() en todos los métodos del controlador
   - Prepared statements PDO (sin inyección SQL)
   - htmlspecialchars() en toda salida de datos
   - Auditoría: created_by y updated_by en tablas principales

5.3 Códigos de reporte
   - 1er Trimestre: EV1T-0001-2026
   - 2do Trimestre: EV2T-0001-2026
   - 3er Trimestre: EV3T-0001-2026
   - Autogenerados con contador anual + relleno de ceros

5.4 Estados del reporte
   - Pendiente → En proceso → Completado / Archivado
   - Badges de Bootstrap: info / warning / success / secondary

5.5 Semáforos de riesgo (ENUM con badges de color)
   - Bajo/Ninguno   → badge bg-success (verde)
   - Intermedio      → badge bg-warning (amarillo)
   - Alto/Muy Alto   → badge bg-danger (rojo)


6. FLUJO DE USUARIO
==============================================================================

6.1 Crear evaluación
   1. Sidebar → Evaluaciones X Trimestre → Nueva Evaluación
   2. Seleccionar paciente (el historial clínico se precarga si existe)
   3. Seleccionar médico
   4. Llenar las secciones del formulario (signos vitales, biometría,
      anatomía, marcadores, entorno, impresión diagnóstica)
   5. Guardar → se crean/actualizan registros en todas las tablas vinculadas

6.2 Editar evaluación
   1. Listado → Editar (ícono lápiz)
   2. Formulario con todos los datos pre-cargados desde las 6 tablas
   3. Modificar y guardar

6.3 Ver evaluación
   1. Listado → Ver (ícono ojo)
   2. Vista detalle con badges de riesgo coloreados
   3. Opciones: Editar, Imprimir

6.4 Imprimir
   1. Listado → Imprimir (ícono impresora)
   2. Plantilla de impresión en HTML sin Bootstrap CDN ni FontAwesome
   3. Dos columnas en formato documento médico
